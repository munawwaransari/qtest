A bag has coins of ₹1, 50 paise, and 25 paise in the ratio of 5:9:4
If the total worth of the bag is ₹42, find the number of 50 paise coins.
[A] 20
[B] 25
[C] 36
[D] 42
C
~
Given:
Total value of bag = 42 rupees = 4200 paise

Since there is a mix of rupee and paise, let us convert everything into paise.
So the ratio in paise would be:

	5x100 : 9x50 : 4x25 => 500 : 450 : 100
	
To solve ratio and part/share questions, first find the value per part using formula:
Note unit must be same, here rupee need to be converted to paise. 

 	                    total value in paise
 	Value per part =  --------------------------
 	                   Sum of ratios (in paise)
 	                      
 	        	        4200         4200      
 	               =   ------------- =  ----- = 4 
 	                    500+450+100      1050 
 	                    
Now individual share can be calculated by multiplying each share ratio to the value per part.

	share or count of 50 paise coins = 9 x 4 = 36  (answer)
	
Note the count is different from the amount of 50 paise. 
If amount needed to be calculated, would be = 36*50 = 1800 paise = 18 rupees.

Six years ago, the ratio in the ages of A, B and C was 2:3:5. If the sum of their present ages is 168, Find their ages.
[A] 30, 40, 50
[B] 30, 45, 55
[C] 30, 45, 65
[D] 30, 40, 75
D
~
Solution:
Let ages of A, B, and C  6 years ago be: 
	
	2x, 3x and 5x respectively (since their ratio is 2:3:5)

So present ages would be:

	2x+6, 3x+6 and 5x+6

Given:
	(2x+6) + (3x+6) + (5x+6) = 168	
	
	2x+3x+5x+6+6+6 = 168 
	
	10x + 18 = 168  =>  10x = 150  => x = 15

There ages are:
	A => 2x = 2*15 = 30
	B => 3x = 3*15 = 45
	C => 5x = 5*15 = 75 
~

Find the mode of the given frequency distribution:
	 ----------------------------
	 |  Class      |  Frequency |
	 --------------+-------------
	 |  10-20      |    10      |
	 --------------+-------------
	 |  20-30      |    10      |
	 --------------+-------------
	 |  30-40      |    16      |
	 --------------+-------------
	 |  40-50      |    12      |
	 --------------+-------------
 
[A] 36
[B] 34
[C] 32
[D] 30
A
~
Formula to calculate mode of frequency distribution:
               f1 - f0
   = L+ --------------------- x h 
            2f1 - f0 - f2
            
   here L  = lower limit of the modal class
        f1 = frequency of the modal class
        f0 = frequency of the preceeding class
        f2 = frequency of the succeeding class
        h  = class width
        
  The modal class is the class with highest frequency.
  In the given table, 16 is the highest frequency, so 30-40 is the modal class 
  
  so f1 = 16

     L  = lower limit of modal class = 30
     f0 = 10
     f2 = 12
     h  = width of the modal class = (40 - 30) = 10
  Therefore mode is 
                 16 - 10                         6             6
    = 30 +  ------------------ x 10   = 30 + --------- = 30 + ---- x 10 = 30 + 6 = 36
             2 x 16 - 10 - 12                 32 - 22          10

Calculate the standard deviation of  5,8,10,12,12,19
[A] 0.00388
[B] 0.00186
[C] 0.00287
[D] 0.00288
C
~
Formula for standard deviation: 
	
	Sqrt ( Sumof(Xi - Mean)^2 / N)
	
where Xi is eacg individual value in the given data
      mean is the mean of the data values
      and N is the count of data values
      
Mean is the average value :  (Sum of all numbers) / Count
Therefore     5+8+10+12+12+19     66   
      mean = ----------------- = ----- = 11
                    6              6           

So Standard deviation = Sqrt ( (5-11)^2+(8-11)^2+(10-11)^2+(12-11)^2+(12-11)^2+(19-11)^2)/6 )
                      = Sqrt ( (36+9+1+1+1+64) / 6)
                      = Sqrt ( 112/6 ) = Sqrt (18.67) = 0.00287
~
