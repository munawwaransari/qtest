- 1
Find derivative of: 

          d    x^5     x^3    x^2     x
          --  ----- + ----- + ---- + ----
          dx    5       3      2      1

[A] x^5 + x^3 + x^2 + x
[B] x^4 + x^3 + x + 1
[C] x^3 + x^2 + x + 1
[D] x^3 + x^2 + x
B
~
Formula for derivation of 
	d/dx (x^n)  => n * x^(n-1)
also  
	d/dx [f(x) + g(x)] = d/dx f(x) + d/dx g(x) = f'(x) + g'(x)   where f'(x) is derivative of f(x)

Therefore 

          d    x^5     x^3    x^2     x
          --  ----- + ----- + ---- + ---- 
          dx    5       3      2      1
          
     =    d    x^5       d   x^3       d   x^2       d    x
          --  -----  +   --  -----   + --  ----   + ---  ---- 
          dx    5        dx   3        dx   2        dx   1
     
          1                1                 1
     =   ---* 5*x^(5-1) + --- * 3*x^(3-1) + ---* 2*x^(2-1) + 1*x^(1-1)
          5                3                 2
          
     =    x^4 + x^3 + x^1 + x^0
     =    x^4 + x^3 + x + 1
~

[A] y^3 - y^2 + y
[B] y^2 - 3y + 5
[C] y^3 - 3y^2 + 5y
[D] y^3 - 6y^2 + 5y
C
~
Definite integral: Integral /b  
                            | f(x) dx = F(b)-F(a), where F(x) = f'(x)
                            /a

and    /             x^(n+1)
       | x^n dx =  ----------
       /               n
                            
also   /                  /           /
       | f(x) + g(x) dx = | f(x) dx + | g(x) dx
       /                  /           ?
                            
Therefore   /  
            | 3y^2 - 6y + 5 dy
            /
            
            /          /          /
         =  | 3y^2 dy - | 6y dy +  | 5 dy
            /          /          /
            
             3*y^3      6*y^2     5*y1
