Consider following C code.
What statement would calculate the correct number of elements in the array.

LINE  1: // Declare and initialize an array
LINE  2: int arr[] = {23, 12, 45, 20, 90, 89, 95, 32, 65, 19};
LINE  3: int n = ? // Calculate the size of the array

[A] sizeof(arr);
[B] sizeof(arr[0]);
[C] sizeof(arr[0]) / sizeof(arr);
[D] sizeof(arr) / sizeof(arr[9]);
D
~
The sizeof operator in C returns the total memory allocated to an array pointer. The returned value depends on the data type of the array as each element is allocated size of the data type. So in this example, int data type takes 4 bytes of memory for each element, and there are 10 elements, so the sizeof(arr) will return 4*10 = 40. 

In order to get the correct number of elements, the total size must be divided by size of an element. This can be done by dividing the total size by size of any one of the elements. Generally 0th element is taken, but any element from the array can be taken provided it is within the array limits.

printf is a variadic function that doesn't inherently know the type of data you pass to it. It relies entirely on the format specifiers in the format string to interpret the bytes pushed onto the function call stack.

When you use %d, printf interprets the memory location corresponding to num_float as if it holds an integer value.

[A] 1 2
[B] 2 2
[C] 0 0
[D] 2 1
B
int main()
{
    union {
        int i1;
        int i2;
    } myVar = {.i1 = 1, .i2 = 2};
    
    printf("%d %d", myVar.i1, myVar.i2);
    
    return 0;
}
~
In C, unlike struct, a union is allocated memory only for the element having maximum size. Here since both members are integer data types, only 4 byte will be allocated as that is the maximum required to store a single integer value.

When union is initialized, i1 is first set to 1. At this time both i1 and i2 have a value os 1.
then when i2 is initialized, values of both i1 and i2 will change to 2.

This is because in a union, all members point to the same memory address, as the memory is allocated only for the maximum size required by one of its members. All other member values will fit in that size.

Which of the following is the correct order of evaluation for the below expression?

	z = x + y * z / 4 % 2 - 1

[A] / * % - + =
[B] * / % + - =
[C] * % / - + =
[D] * % / + - =
B
~
Precedence of Arithmetic Operators (from highest to lowest):

Parentheses (): Expressions enclosed in parentheses are evaluated first, overriding other precedence rules.
Unary Plus + and Unary Minus -: These operators apply to a single operand and have higher precedence than binary arithmetic operators.

Multiplication *, Division /, and Modulus %: These operators have equal precedence and are evaluated from left to right (associativity).

Addition + and Subtraction -: These operators have the lowest precedence among arithmetic operators and are also evaluated from left to right (associativity).
~
