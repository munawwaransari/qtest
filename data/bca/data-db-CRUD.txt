[B] Third Normal Form (3NF)
[C] Fourth Normal Form (4NF)
[D] Fifth Normal Form (5NF)

To convert a table from 2NF to 3NF, identify any transitive dependencies where a non-key attribute depends on another non-key attribute, and then separate the transitively dependent attributes into a new table. For example, a table with CourseID, InstructorName, and InstructorOffice can be converted to 3NF by creating two tables: a Courses table (CourseID, InstructorName) and an Instructors table (InstructorName, InstructorOffice) to remove the transitive dependency of InstructorOffice on CourseID via InstructorName.

Which statement is true about views?

[A] A view is a physical entity in a database, directly storing data in rows and columns.
[B] A view is a virtual table or a logical representation of data derived from one or more underlying tables (or other views).
[C] Data in a view is permanently stored until explicitly deleted or modified.
[D] Views are not dependent on the underlying tables for their data
B
~
A view is a virtual table or a logical representation of data derived from one or more underlying tables (or other views).

A view does not physically store data; it stores the SQL query definition that retrieves data from its base tables.

Views do not consume physical storage space for data, only for their definition.

Data manipulation on a view is generally not directly supported, as changes must be reflected in the underlying base tables.
Views are dependent on the underlying tables for their data; if the base tables are modified or deleted, the view may become invalid.

Views are often used for security, simplifying complex queries, or presenting specific subsets of data to users without exposing the entire underlying table structure.
~

A self join is a SQL query where a table is joined with itself, allowing you to compare or relate rows within the same table. It's used to query hierarchical data, like finding an employee's manager, or to compare records that have a relationship within the same table.
