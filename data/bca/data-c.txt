What will be size of the struct my_struct?
[A] 9
[B] 12
[C] 8
A
#pragma pack(1)
struct my_struct {
   int a;
   float b;
   char c; // padding ? 
};
#pragma pack()
printf("size of my_struct = %ld\n", sizeof(struct my_struct));
~
The #pragma pack directive is a compiler-specific extension used to control the alignment of struct members. It allows a programmer to specify a maximum alignment boundary for members within a struct.

With #pragma pack(1), the compiler is forced to pack the struct members on 1-byte boundaries, eliminating padding. In this case, sizeof(struct my_struct) would be 9 bytes (4 + 4 + 1).

struct my_struct {
   int a;
   float b;
   char c; // padding ? 
};
printf("size of my_struct = %ld\n", sizeof(struct my_struct));
~
To ensure natural alignment for all members within a struct, the compiler may insert "padding" bytes. This padding ensures that each member starts at an address that is a multiple of its own size.

Many systems, especially 32-bit architectures, have a default alignment of 4 bytes. This means data types like int (which are typically 4 bytes) are most efficiently accessed when their memory addresses are multiples of 4.

In this example char type will be padded to make the size event to ensure natural alignment. Explicit padding can be defined using directive #pragma pack(n) if this behavior is not desired.

What will be the output of below code?
[A] 20
[B] 10
A
void swap(int *ptr1, int *ptr2) 
{
   int *temp = ptr2;
   ptr2 = ptr1;
   ptr1 = temp;
}
int main() 
{
    int a=20, b=10;
    swap(&a, &b);
    printf("%d\n", a);
}
~
If you attempt to swap the addresses themselves within a function by passing pointers to pointers, you would only be swapping the local copies of those pointers within the function. The original pointers in main would remain unchanged, and thus, the variables they point to would not be swapped.
~

What will be the output produced by the following C code?
[A] 65 
[B] 'A'
[C] error
B
union Data {
    int i;
    char str[4];
};

int main() {

    union Data data = {};
    data.str[0] = 'A';
    printf("data.i = %c\n", (char)data.i);
    return 0;
}
~
A union in C is a special data type that allows different data types to be stored in the same memory location. Unlike structures, where each member occupies its own distinct memory space, a union allocates memory only for its largest member, and all other members share that same memory. This means that at any given time, only one member of the union can hold a meaningful value.
~

./program 1 2 3 4
[A] 5 
[B] 4
[C] ./program
[D] 1
C
int main(int argc, char**argv)
{
  printf("%s\n", argv[0]);
}
~
The main function in C can accept arguments from the command line, enabling programs to receive input at runtime.

argc (Argument Count): This is an integer variable that stores the number of command-line arguments passed to the program, including the program's name itself. Its value will always be at least 1, as argv[0] always contains the program's name.

argv (Argument Vector): This is an array of character pointers (or an array of strings). Each element in argv points to a string representing a single command-line argument. argv[0] typically contains the name of the executable program.
