[A] 35
[B] 36
[C] 37
C
~
using base factorization method:
   (10101)<sub>2</sub> 
   = 1x2<sup></sup> + 0x2<sup></sup> + 1x2<sup></sup> + 0x2<sup></sup> + 1x2<sup></sup> 
   = 1x32 + 0 + 1x4 + 0 + 1
   = 32 + 4 + 1
   = 37

Convert (ABCD)<sub>16</sub> to Octal?

[A] (125715)<sub>8</sub>
[B] (125716)<sub>8</sub>
[C] (125717)<sub>8</sub>
A
~
using Nibble grouping for binary, and then rouping 3-bits for octal

     (A    B    C    D)<sub>16</sub>
   = (1010 1011 1100 1101)<sub>2</sub>      [Replace each nibble by hex digit]
   = (1010101111001101)<sub>2</sub>
   = (  1 010 101 111 001 101)<sub>2</sub>  [Regroup 3-bits starting from LSB]    
   = (001 010 101 111 001 101)<sub>2</sub>
   = (  1   2   5   7   1   5)<sub>8</sub>  [Replace each 3-bits grop by octal digit]
   = (125715)<sub>8</sub>
~

Convert (765)<sub>8</sub> to Hexa-Decimal?

[A] (5F1)<sub>16</sub>
[B] (1F5)<sub>16</sub>
[C] (1E4)<sub>16</sub>
B
~
using Nibble grouping for binary, and then rouping 3-bits for octal

     (7   6   5)<sub>8</sub>
   = (111 110 101)<sub>2</sub>      [Replace each octal digit by 3-bit binary]
   = (111110101)<sub>2</sub>
   = (1 1111 0101)<sub>2</sub>      [Regroup nibbles starting from LSB]    
   = (00001 1111 0101)<sub>2</sub>
   = (1     F    5)<sub>16</sub>     [Replace each nibble by hexa-decimal digit]
   = (1F5)<sub>16</sub>
